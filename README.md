# ML-Data-Preprocessing

A collection of hands-on projects focused on **EDA, data cleaning, preprocessing, and feature engineering** for Machine Learning.

These projects focus on understanding and transforming **raw data into clean, meaningful, and model-ready data** before model building.

## Projects

### Project 1 — Medical Insurance Data Analysis

Worked with a medical insurance dataset to explore how factors such as **age, BMI, smoking status, children, gender, and region** relate to insurance charges.

**Covered:**
- Exploratory Data Analysis (EDA)
- Data Cleaning
- Data Preprocessing
- Feature Engineering
- Feature Scaling
- Correlation & Pearson Correlation
- Hypothesis Testing
- Statistical Analysis

**Why it matters:**  
The project demonstrates how raw data is investigated, cleaned, transformed, and prepared before it can be effectively used for Machine Learning.

**Dataset:** `insurance.csv` is included in this repository.

**Notebook:** [Google Colab](https://colab.research.google.com/drive/1BxAS2_KnAlnydWOrhf88_oIdzSHQClR6)
