# ML Data Preparation

A collection of hands-on projects focused on **EDA, Data Cleaning, Preprocessing, Feature Engineering, and Statistical Analysis** for Machine Learning.

The projects focus on understanding how raw data is explored, cleaned, transformed, and prepared for ML.

## Projects

### Project 1 — Medical Insurance Dataset
**Focus: Numerical Data**

Worked with medical insurance data to understand relationships between numerical features such as **Age, BMI, Children, and Charges**.

**Covered:**
- EDA and data visualization
- Data cleaning
- Feature preprocessing
- StandardScaler
- Pearson correlation
- Hypothesis testing and p-values
- Feature analysis

The project shows how numerical data can be explored and transformed into **clean, model-ready data**.

---

### Project 2 — Heart Disease Dataset
**Focus: Categorical Data**

Worked with heart disease data to understand how categorical features such as **Sex, ChestPainType, ExerciseAngina, RestingECG, and ST_Slope** relate to the `HeartDisease` target.

**Covered:**
- Categorical data analysis
- Count plots and EDA
- Binary encoding
- One-hot encoding
- Chi-square test
- p-value and significance level
- Feature analysis

This project focuses on understanding how **categorical variables can be analyzed, encoded, and prepared for Machine Learning**.
